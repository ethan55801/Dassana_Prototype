# Dassana

Dassana is a professional religious content consultancy website for Phyu Mar Lwin, a Religious Studies scholar specializing in Theravada Buddhism, Pali epigraphy, Burmese Buddhism, and material religion in Southeast Asia.

## Website

The site is designed for GitHub Pages and uses only static HTML, CSS, JavaScript, and a local profile photo.

## Local preview

Run the included PowerShell server from the project folder:

```powershell
powershell -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\server.ps1
```

Then open http://127.0.0.1:8000/
